# lck-fantasy

A free, season-long fantasy game for the LCK (League of Legends Champions Korea) that copies FPL's structure. You get a budget, a squad with a bench, weekly transfers, a captain, chips with LCK-themed names, and global and supporter leagues. The theme is Korean.

Nothing is built yet. The LCK Cup (January to March 2027) is the planned beta.

- [Research](docs/research/): the competitors, the LCK season, scoring and pricing, weekly logic and onboarding.
