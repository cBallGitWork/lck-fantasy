# convex/scoring

Scoring rules as data, the engine that turns stats into series points, and the re-score.

- `game.ts`: one game's points by line, for a player and for the coach (spec/05).
- `series.ts`: a series' points: the best games, and the coach's win or loss points.
- `fixtures.ts`: spec/05's tables and a 2025 game, for tests only. The live tables are data.
