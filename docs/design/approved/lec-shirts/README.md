# LEC shirts

Flol's kit for each of the ten LEC teams, Pro Evolution Soccer style: each team's current jersey at a glance, redrawn on the LCK shirts' cut ([shirts](../shirts/README.md)), with the Flol maker mark top left and the [LEC crest](../lec-crests/README.md) top right. The LEC game is an idea in [docs/to-grill.md](../../../to-grill.md), not specced; these wait for it.

**Approved:** Craig, 18 Nov 2026 ("Yes happy ship it").
