# Tier crests

Overall's tier mark: Flol's own winged crest, one for each of the ten tiers and a ring for Unranked. Drawn after League's ranked crests (Craig, 28 Nov 2026: the shield could be better, look at League), never Riot's artwork.

## How it grows

One blade a side at Iron, four at Challenger, each tier's wider and taller than the last; lower fangs from Gold; a spike over the gem from Diamond; a three-point crown for Grandmaster and Challenger. Challenger's gem and crown are gold.

## Where it shows

Leagues (Overall's table, the tier panel, the list), Home's head, Points' Leagues panel, the profile and Help's Ranks table.
