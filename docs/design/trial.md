Does a short kit beat today's `/design` on its own? One screen is drawn both ways and Craig picks
blind (Craig, 18 Nov 2026, after a second opinion found the long template too long and mostly bans;
it is kept as background in `docs/research/design-without-slop/template-long-draft/`).
`plate.md` stays binding. Nothing here moves to Forge until the trial has a winner.

## The steps

1. **One dataset.** Every picture uses the same made-up week, and one fact has one value everywhere.
2. **Two real references,** saved in `docs/design/references/` with a line each on what is borrowed.
   Translate, never copy.
3. **Signature.** One line naming the object that carries the screen.
4. **Plan audit.** Before drawing, write the ground, accent, type and layout of each direction, then
   ask of each choice: would I do this for any similar page? Each yes is revised, as
   `Was: … Now: … Why: …`.
5. **Three directions,** each with a different ground, accent and Latin face, and a different way of
   showing the data (row height, what sits above the fold, how figures are drawn). Directions that
   differ only in colour count as one.
6. **Two widths.** Each direction at 1440 and at 390.
7. **The control.** The same screen drawn with today's `/design`, on the same data, by a session that
   has not read this page.
8. **The lint.** The EPL app's nine checks (`epl-draft-intel/tools/ui/designlint.mjs`), ported, run on
   every picture: middle dots, key headings, typed stars, a source named on screen, radius, gradients,
   tracked capitals, blur, soft shadows. Rules the plate contradicts are switched off.
9. **The panel,** under `panel-rules.md`: lettered pictures, the control and one ringer among them,
   ranked, then the sceptic.
10. **Craig picks blind,** from lettered pictures. His reactions go in the taste log, below.

## Watch for

The plate's six Never items bind. These nine came from the 18 Nov site walk; in the trial each is a
finding for Craig, never a rule, until he says so.

1. A box for every state, so every state looks the same.
2. The figure face on dates, times and labels.
3. A row of equal-weight keys on one object.
4. One page skeleton on every page.
5. Dashed placeholder boxes setting a built page's rhythm.
6. Generic items where the game has real ones.
7. Unselected items greyed, so the page looks disabled.
8. Filter chips as pills, the chosen one filled.
9. A control that does nothing and says nothing.

When a tell is removed, look at what replaced it: a model falls back to the next default.

## What decides it

- Craig prefers a kit direction to the control, blind: the kit goes on to a second screen.
- He prefers the control, or can't tell them apart: the kit is dropped and `/design` stays as it is.
- The LEC brand check, the fuller lint and the Forge move wait for the first result.
