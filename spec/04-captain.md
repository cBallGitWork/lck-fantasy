## The armband

- Each gameweek a manager names a captain and a vice-captain from the six starting players: the
  five roles and the flex ([spec/01](01-squad-and-slots.md)). Never the coach, never the bench.
- The captain's points are multiplied. The multiplier's value is settled with scoring
  ([spec/05](05-scoring.md)) and is data, never code.
- If the captain plays no game in the gameweek, the vice-captain takes the multiplier. If neither
  plays, nobody does.
