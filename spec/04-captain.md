# Captain

Craig's answers only, from the `/grill`s of 12 and 17 Nov 2026. Where this file is silent the
rule is FPL's, or FPL's logic ([SPEC.md](../SPEC.md), the base assumption). Open questions are in
[docs/to-grill.md](../docs/to-grill.md).

## The name

- FPL's word: the **Captain**, with a C badge, everywhere: screens and spec (Craig, 17 Nov 2026;
  Carry before).
- There is no vice-captain: substitutes are rare in the LCK, so it is one less thing to pick
  (Craig, 17 Nov 2026).

## The armband

- Each gameweek a manager names a Captain from the six starting players: the five roles and the
  flex ([spec/01](01-squad-and-slots.md)). Never the coach, never the bench.
- The Captain's points are multiplied. The multiplier's value is settled with scoring
  ([spec/05](05-scoring.md)) and is data, never code.
- If the Captain plays no game in the gameweek, nobody takes the multiplier.
- Benching the Captain passes the armband to the player who comes on: Faker (Captain) goes off
  for Bdd, so Bdd is the Captain (Craig, 15 Nov 2026).
- Under the Double Captain buff a second Captain is picked by the same rules, both wear C, and
  both score ×2 that week ([spec/06](06-buffs.md)).
