## The names

- FPL's captain is the **Carry**, and the vice-captain the **Vice-carry**, everywhere: screens and
  spec (Craig, 12 Nov 2026, in the chips grill).

## The armband

- Each gameweek a manager names a Carry and a Vice-carry from the six starting players: the five
  roles and the flex ([spec/01](01-squad-and-slots.md)). Never the coach, never the bench.
- The Carry's points are multiplied. The multiplier's value is settled with scoring
  ([spec/05](05-scoring.md)) and is data, never code.
- If the Carry plays no game in the gameweek, the Vice-carry takes the multiplier. If neither
  plays, nobody does.
