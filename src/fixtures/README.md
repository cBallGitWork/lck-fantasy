# src/fixtures

Made-up data the screens are built on until the backend wires real data.

Only data two or more screens share lives here. A screen's own made-up data goes in its folder (`src/screens/<name>/fixtures.ts`), so screens built side by side never edit the same file.

- `week3.ts`: the LCK Cup Week 3 the approved pictures share: teams, the series at Points' moment and final, Week 4's fixtures and deadline, the sample manager Baron Steal FC, and the squads, prices and points of the Points, Pick Team, Stats and Perfect game pictures.
